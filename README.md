# Pack B – Agentic ITSM Resolution Platform

An enterprise-grade Agentic AI platform for IT Service Management.

## Key Capabilities
- Agentic AI with planner–executor architecture
- Retrieval-Augmented Generation (RAG) over real documentation
- MCP-based tool boundaries for safe execution
- Long-term memory without prompt pollution
- Human-in-the-loop governance via n8n
- Secure zero-trust exposure using Cloudflare Tunnel
